一个写代码的地方

新手推荐 IntelliJ IDEA 社区版；也可以使用 VS Code + Java 扩展。记事本理论上也行，但会很痛苦。

IntelliJ IDEA ↗ VS Code Java ↗
Windows 安装逐点清单 点开，照着做 · 约 15 分钟
  1. 下载 JDK 21。打开 adoptium.net，在 Releases 里选 JDK 21，Operating System 选 Windows，Architecture 选 x64，Package Type 选 JDK，下载 .msi 安装包。
  2. 安装。双击安装包，保持默认选项；在功能选择页勾选 Set JAVA_HOME variable 和 Add to PATH，然后 Install。
  3. 验证。关闭旧终端，重新打开 PowerShell，依次执行 java -version 和 javac -version。两个都能显示版本号就成功。
  4. 安装编辑器。下载 IntelliJ IDEA Community，安装时一路默认。第一次打开选择 New Project，Language 选 Java，JDK 选刚装好的 21。
  5. 创建第一段代码。在项目左侧展开 src，右键 → New → Java Class，输入 HelloJava；把第 1 关的代码粘进去，点击绿色三角运行。

macOS 用户下载 .pkg 后按默认步骤安装即可；如果使用 VS Code，请先安装 Extension Pack for Java，再新建 HelloJava.java。安装路径里尽量避开中文和空格。

CHECK 装好之后

打开终端，验证两行命令。

Windows 可以搜索「PowerShell」；macOS 打开「终端」。都能看到版本号，就说明 JDK 准备完毕。

如果 java 有版本但 javac 找不到，通常是只装了运行环境 JRE，而不是完整的 JDK。

01 / 规则

选择器 + 声明块

.card {
  color: #173b2b;
}
选择器：给谁 属性：改什么 值：改成什么

每条声明都以分号结尾；注释写成 /* 说明 */，浏览器会忽略它。

02 / 常用属性

先记住这 10 个

  • color文字颜色
  • background背景
  • padding内边距
  • margin外边距
  • border边框
  • border-radius圆角
  • font-size字号
  • display布局方式
  • gap项目间距
  • transition过渡动画

03 / 选择器

精准点名

  • p所有 p 标签
  • .cardclass 为 card
  • #heroid 为 hero
  • .card pcard 里面的 p
  • .card:hover鼠标悬停时
  • @media按屏幕宽度适配

class 可以复用；id 在一页中应当唯一。

这个页面的样式就写在 styles.css 里。学完前十关，打开它，你会认出大部分规则。
